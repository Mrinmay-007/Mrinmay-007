# Icon sources

Python, FastAPI, MySQL, NumPy, Pandas, scikit-learn, Git, GitHub, YouTube, and Instagram marks use inline SVG paths from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The local paths make no network requests; the CC0 text is included in `SimpleIcons-CC0.txt`.

The Matplotlib mark is the project’s official SVG from [matplotlib/matplotlib](https://github.com/matplotlib/matplotlib/blob/main/lib/matplotlib/mpl-data/images/matplotlib.svg); its license is included in `Matplotlib-LICENSE.txt`. The LinkedIn `in` glyph follows its [official logo download page](https://brand.linkedin.com/downloads). SQL and Topmate use original text marks, with no third-party brand artwork. The platform and technology names remain written beside each mark.
